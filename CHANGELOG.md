# Changelog

## 0.1.0 (2026-11-23)

First release.

- `g560d` user service: subwoofer level, LED effects and brightness, and the speaker's 10-band hardware EQ, re-applied on login, replug and resume.
- GNOME Shell extension (GNOME 48–50): top-bar menu with sliders, light effects, color swatches, an inline custom color picker with recent colors, and sound profiles. Scrolling on the icon changes the subwoofer level.
- Settings window: per-zone lights, EQ editor with custom profiles, startup-animation toggle, lights off on lock/suspend, and save to speaker.
- `g560` command-line tool.
- `install.sh` for install, update, status and uninstall.
